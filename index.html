Nexus

A responsive, dark-mode-first social & communication scaffold inspired by Discord and Instagram. This repository contains a Next.js frontend (app/) and an Express + Socket.io backend (server/).

Open Frontend (app/) Open Backend (server/) Repo on GitHub
Local dev: run the backend at port 4000 and the frontend at port 3000. See README.md in the repository root for full instructions.
Created with ❤️ — Dark-mode-first UI • Tailwind • Next.js • Express • Socket.io
What's here
Next.js app (app/), Express server (server/), Tailwind config, example Socket.io & WebRTC placeholders.
Supabase
If you plan to use Supabase, add your DB schema and storage rules. See the SQL schema provided in the PR for users, posts, rooms, messages, and media.
